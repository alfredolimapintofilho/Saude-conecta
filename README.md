# 🏥 Saúde Conecta - Patos/PB

> A saúde da cidade na palma da sua mão.

Plataforma digital de saúde desenvolvida para o município de **Patos - Paraíba**.  
O sistema permite que cidadãos se cadastrem, façam login e visualizem as unidades de saúde da cidade em um mapa interativo.

---

## ✨ Funcionalidades

- ✅ Cadastro de cidadãos (com validação de CPF e LGPD)
- ✅ Login por CPF e senha
- ✅ Mapa interativo das unidades de saúde de Patos-PB
- ✅ Filtros por tipo de unidade (Hospital, Maternidade, UBS, Emergência)
- ✅ Informações de endereço, telefone e horário de funcionamento
- ✅ Interface moderna e responsiva

---

## 🛠️ Tecnologias Utilizadas

| Camada       | Tecnologia              |
|--------------|-------------------------|
| Frontend     | React + Vite            |
| Estilização  | Tailwind CSS            |
| Mapas        | React Leaflet           |
| Backend      | PHP 8+                  |
| Banco de Dados | MySQL                 |
| Autenticação | Password Hash (BCRYPT)  |
