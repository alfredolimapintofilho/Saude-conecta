# 🏥 Saúde Conecta

> Conectando cidadãos a serviços de saúde com eficiência, transparência e agilidade.

O **Saúde Conecta** é uma plataforma web desenvolvida para facilitar o acesso da população a atendimentos de saúde, agendamentos de consultas, acompanhamento de histórico médico e integração entre cidadãos e profissionais de saúde.

---

## 🚀 Funcionalidades Principais

- **Portal do Cidadão:**
  - Cadastro e login seguro com validação de dados.
  - Agendamento e cancelamento de consultas médicas.
  - Visualização de histórico de atendimentos e prescrições.
- **Painel do Profissional / Gestão:**
  - Gerenciamento de agenda de atendimentos.
  - Registro de prontuários eletrônicos simples.
  - Relatórios de atendimentos e demandas por especialidade.

---

## 🛠️ Tecnologias Utilizadas

- **[React](https://react.dev/)** + **[Vite](https://vitejs.dev/)**

- **[React Router DOM](https://reactrouter.com/)** (Navegação SPA)
- **[Axios](https://axios-http.com/)** (Consumo de API HTTP)

### Backend (Opcional/Futuro)
